南京轨道交通互动地图（高清矢量重构版）

本版仅重构地图显示结构，其余既有功能与交互保持不变。

重构内容：
1. 底图由原 1200×1642 PNG / MP4 背景改为 PSD 原始 4488×6142 分辨率高清 PNG。
2. 不再使用低分辨率 MP4 作为线路动画背景。
3. 14 条线路使用 SVG 路径在浏览器中实时绘制，缩放后线路保持矢量清晰。
4. 线路移动效果改为 SVG 实时动画，仍按原图例线路顺序循环播放。
5. “暂停动画 / 播放动画”按钮继续有效。

保留功能：
- 鼠标滚轮缩放（100%—500%，以鼠标位置为缩放中心）
- 放大后左键拖动平移
- ＋ / − / 复位按钮与缩放比例显示
- 点击线路自动聚焦后进入对应线路介绍页
- 点击景点自动聚焦并弹出介绍
- 放大后仍可连续点击其他景点切换介绍
- 介绍框右上角 × 与 Esc 均可关闭，关闭不重置缩放
- 景点介绍框右下角继续显示 PSD 中对应景点图标
- 14 条线路快捷入口与 route.html 介绍页不变

文件：
- index.html：互动地图首页
- route.html：线路介绍页
- data.js：线路、颜色、景点及交互数据
- map-data.json：数据 JSON 备份
- assets/map-base-hd.png：PSD 原始 4488×6142 高清底图
- assets/attraction-icons/：17 个景点图标

使用：
1. 可直接双击 index.html 预览。
2. 推荐在本文件夹运行：python -m http.server 8000
   浏览器访问：http://localhost:8000/
3. 上线时可将整个文件夹部署到静态网站服务器。

本版本底图已替换为用户提供的“鎏金底图.psd”高清合成图（4488×6142），其余交互功能保持不变。

本版本新增线路两段式点击交互：
- 第一次点击地图上的线路：自动聚焦放大、线路保持高亮，移动光标沿该线路循环运行；
- 再次点击当前已选中的同一线路：跳转至对应线路介绍页；
- 若改点其他线路：切换选中线路，不会直接跳转；
- 点击“复位”：取消当前线路选择并恢复全线路轮播动画。
